# UPI Transaction Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing **UPI transaction data using SQL** to understand transaction patterns, payment performance, customer behavior, bank usage, device usage, and fraud-related activities.

The analysis uses SQL queries to extract meaningful business insights from UPI transaction data.

## 🎯 Project Objective

The main objective of this project is to analyze UPI transactions and understand:

* Transaction volume and transaction amount
* Transaction success rate
* Common transaction types
* Merchant category performance
* State-wise transaction activity
* Sender and receiver bank usage
* Device usage patterns
* Customer payment behavior
* Fraudulent transactions and fraud rate

These areas help businesses understand UPI payment activity and identify important transaction patterns.

## 🗂️ Dataset

**Dataset:** UPI Transactions

The dataset contains transaction-level information related to UPI payments.

Key analysis areas include:

* Transaction details
* Transaction amount
* Transaction status
* Transaction type
* Merchant category
* State
* Sender and receiver banks
* Device information
* Customer age group
* Transaction time
* Fraud information
